# Лапки Redux Toolkit (ЛР № 5)

React-приложение «Лапки», в которое добавлено глобальное хранилище на Redux Toolkit. Избранные питомцы хранятся в store, поэтому кнопка-сердечко в карточке, счётчик в шапке экрана и панель «Избранное» всегда показывают одинаковые данные, хотя напрямую друг с другом не связаны.

## Стек

React 18, Vite, Redux Toolkit (`@reduxjs/toolkit`), React Redux (`react-redux`), PropTypes, CSS Modules.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

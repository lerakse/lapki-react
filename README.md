# Лапки — UI-компоненты

Базовая структура веб-приложения на React для мобильного приложения «Лапки»
(автоматизация адаптации животных из приютов с ИИ-ассистентом).
Компоненты соответствуют макетам из ЛР1 (Figma).

## Стек

React (функциональные компоненты, JSX, `useState`), Vite, PropTypes, CSS Modules.

## Запуск

```
npm install
npm run dev
```
Откройте адрес из терминала (обычно http://localhost:5173).
